# X Ranking Simulator

Offline research simulator for the public weighted RankingScorer path. It is not a production-score or virality predictor.

The first version reproduces public default weights, negative-score offset behavior, author-diversity decay, out-of-network discount, mutual-follow reply boost, and VQV gating. It intentionally does not claim to reproduce Phoenix inference, experiment overrides, cold-start assignment, VMRanker reranking, visibility filtering, or unpublished rules.
